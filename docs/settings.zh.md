# 配置

[English](https://github.com/shenjiecode/pi-wechat-assistant/blob/main/docs/settings.md) | 简体中文

执行 `/wechat config` 打开 pi 自带的选择和输入窗口。列表直接显示当前值和简短用途。图片设置先提供常用预设（不等待 / 2 / 8 / 15 秒，以及 10 / 20 / 50 MB），也可选择“自定义”，按单位和范围提示填写。先选配置项，再选值；每次确认单独保存。Esc 取消当前值选择、从高级设置返回，或关闭主菜单。打开设置不会启动桥接，也不会注册发送工具。无 UI 时显示文本；`/wechat config show` 始终显示文本。

| 位置 | 配置项 | 默认值 | 为什么需要 |
| --- | --- | --- | --- |
| 常用 | 收件回执通知 | 开启 | 控制文字和图片收件确认；关闭不影响 AI 回复、文件保存结果及错误提示。 |
| 常用 | 文字 / 图片回执内容 | 内置文案 | 分别自定义内容；留空恢复默认，Esc 取消修改。 |
| 常用 | 双向同步 | 关闭 | 控制是否同步新的电脑输入和 AI 回复；关闭后仅回传微信任务回复。 |
| 常用 | 完成摘要 | 关闭 | Pi 本轮处理结束后，向微信发送一条简短的 AI 回复。 |
| 常用 | 自动启动微信桥接 | 关闭 | 打开 pi 会话时尝试连接微信。TUI 下若桥接被其他会话持有，按下方「持锁接管方式」处理；无界面模式只报告锁占用。开启时会引导把接管方式改为自动。不改变当前桥接启停状态。 |
| 常用 | 持锁接管方式 | 询问 | 其他会话持有协作交接（0.4.4+）的桥接时，询问 = 弹窗确认，自动 = 直接请求旧会话交接。无界面模式始终不自动接管。 |
| 常用 | 微信消息标识与排版 | 开启 | 微信消息加来源标记（默认 [微信]），引导 AI 用短段落和文字提问，并拦截已配置的本机提问工具；有任务运行时等待其结束再修改。 |
| 常用 | 回复模板操作 | 内置模板 | 查看模板及路径、导出默认模板、不覆盖已有文件、重载编辑后的模板；这些是操作，不额外增加开关。 |
| 高级 | 微信端 /tools 修改本机权限 | 关闭 | 允许微信 `/tools` 命令修改本机工具权限；不控制微信文件和图片发送工具的启停。 |
| 高级 | 连发图片合并等待 | 8000 毫秒 | 微信连发多张图时凑成一批处理，文字到来可提前处理；范围 0–60000，0 表示不等待。 |
| 高级 | 单张图片下载上限 | 50 MB | 限制下载图片的大小，最低 1 MB；不改变发出文件的独立大小限制。 |

自定义来源标识、阻塞提问工具名单属于少数特殊接入需求，继续通过 `config.json` 修改，不放进日常设置窗口。回复措辞放在 `wechat-prompt.md`。登录凭据、消息发送凭据、锁归属和当前运行状态不作为可编辑配置项。

配置保存在 `~/.pi/agent/wechat-assistant/config.json`。保存后本进程和以后新开的会话使用新值；其他已打开进程有自己的缓存，不会自动重读。若要换进程修改配置，先重载扩展或重新打开会话。图片环境变量仍作为没有对应 JSON 配置时的回退值，窗口显示实际生效的图片设置。本次没有新增跨进程配置实时同步。

原有命令保留，新增显式命令 `/wechat config auto-start on|off`、`/wechat config handoff ask|auto`、`/wechat config remote-tools on|off`。回复模板的位置和系统提示词行为见[微信回复规则](https://github.com/shenjiecode/pi-wechat-assistant/blob/main/docs/wechat-source.zh.md)。

## 完成摘要

用 `/wechat config summary on` 开启摘要，用 `/wechat config summary off` 恢复逐条发送 AI 回复。也可以在常用设置里切换，从下一条用户请求生效。新安装和从旧版升级都默认关闭。`/wechat config show` 会显示保存的设置，以及当前 Pi 实际能使用的模式。

Pi 可能会自动重试、压缩上下文或继续处理追加的工作。桥接从 `agent_before_settle` 读取本轮处理结果，等 `agent_settled` 确认收尾后发送。缺少所需事件的旧版 Pi 使用实时回复。[Pi 官方事件流程](https://github.com/earendil-works/pi/blob/v1.6.0/packages/coding-agent/docs/extensions.md#lifecycle-overview)

通知包含任务简述和最近一条可同步的最终回复。开启微信回复规则时，会引导模型在开头写明任务完成、任务失败，或需要你回答的问题和选项。微信优先发送标出的结果段，提问会保留选项。普通短回复完整发送，长回复摘取首尾并提示到 Pi 查看全文。生成摘要无需额外调用模型。模型请求报错和用户取消由 Pi 的事件确认。电脑端回复仍由双向同步设置控制。

收件回执、主动发送的文件和命令回复各自独立。如果也想关闭普通收件回执，可执行 `/wechat config ack off`。微信以 `ret=-2` 拒收摘要时，会进入现有待发箱，在收到新的微信消息后尝试补发。

## 收件回执通知

通过 `/wechat config ack on|off` 或常用设置窗口开关。兼容 `config.json` 中已有的 `"sendAck": false`；默认开启。

- `/wechat config ack-text 已收到，正在处理…` 设置文字消息回执。
- `/wechat config image-ack-text 图片已收到，可以继续补充说明。` 设置图片批处理回执。
- 不带内容执行上述文案命令可恢复默认。修改文案不会自动开启通知。

JSON 字段为 `sendAck`、`ackText`、`imageBatchAckText`；未设置或内容为空白时使用内置文案。纯图片批次最多发送一次回执；同时带文字和图片的消息沿用不额外发送回执的行为。文件保存结果和错误提示仍保留。通过命令修改后，对后续回执生效；直接编辑 JSON 后需重载扩展或重新打开会话。
